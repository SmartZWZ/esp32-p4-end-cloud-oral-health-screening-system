# 齿镜网页端百炼实时语音助手部署指南

本指南部署的是网页端基础版：网页采集麦克风音频、百炼实时语音识别与语音回复、按账户保存对话、查看历史对话，并编辑当前对话的标题和助手指令。

它暂时不连接 ESP32-P4，也不包含 MCP 控制。

## 0. 重要前提：网页语音必须使用 HTTPS

当前正式站点为 `https://wwwxsh.cn/`。现代 Edge/Chrome 会把麦克风视为敏感权限；当前域名已启用 HTTPS，满足网页麦克风的安全上下文要求。

要正式使用语音功能，后续需要：

1. 已将 A 记录指向 `8.138.230.100`。
2. 已在宝塔网站中绑定 `wwwxsh.cn`。
3. 已申请并部署证书，开启“强制 HTTPS”。
4. 按下面配置将 `AI_GATEWAY_ALLOWED_ORIGIN` 固定为 `https://wwwxsh.cn`。

不要把 API Key 写进 HTML、JS、ESP32 固件或浏览器地址栏。

## 3. 创建百炼运行时配置

在服务器终端执行：

```bash
SITE_ROOT=/www/wwwroot/8.138.230.100_667
RUNTIME=/www/wwwroot/chijing_runtime

install -d -m 750 -o root -g www "$RUNTIME/ai"
nano "$RUNTIME/ai/bailian.env"
```

在 nano 中粘贴下面内容。`BAILIAN_API_KEY` 只填你自己的百炼 API Key；`AI_GATEWAY_SECRET` 通过后面的命令生成，不要使用示例文字。

```ini
BAILIAN_API_KEY=粘贴你的百炼API_Key
BAILIAN_REALTIME_WS_URL=wss://ws-sk9a2fzftxh5to2c.cn-beijing.maas.aliyuncs.com/api-ws/v1/realtime
BAILIAN_REALTIME_MODEL=qwen-audio-3.0-realtime-plus
AI_GATEWAY_SECRET=粘贴下一步生成的随机密钥
AI_GATEWAY_ALLOWED_ORIGIN=https://wwwxsh.cn
AI_GATEWAY_PUBLIC_PATH=/ai-gateway/
AI_GATEWAY_LISTEN_HOST=127.0.0.1
AI_GATEWAY_LISTEN_PORT=8765
```

说明：你提供的 `compatible-mode/v1` 与 `api/v1` 是 HTTP API 地址；实时语音助手应使用 WebSocket 地址 `/api-ws/v1/realtime`。上面的主机名来自你的业务空间地址。标准版通常使用 `qwen-audio-3.0-realtime-plus`；如百炼控制台在模型详情显示了不同的**模型 API 名称**，以控制台名称替换这一行。

另开一个终端或先在 nano 保存后，生成密钥：

```bash
openssl rand -hex 32
```

把输出的整串随机字符填入 `AI_GATEWAY_SECRET=` 后面。nano 保存快捷键：`Ctrl+O`、回车、`Ctrl+X`。

然后限制密钥文件权限；PHP-FPM 和语音网关都以宝塔常见的 `www` 用户运行，因此使用 `root:www` 和 `640`：

```bash
chown root:www "$RUNTIME/ai/bailian.env"
chmod 640 "$RUNTIME/ai/bailian.env"
```

## 4. 允许 PHP 读取运行时配置

此前 `.user.ini` 的 `open_basedir` 可能只允许网站目录和图片存储目录，需要补充 `chijing_runtime`。

```bash
chattr -i "$SITE_ROOT/.user.ini" 2>/dev/null || true
printf '%s\n' 'open_basedir=/www/wwwroot/8.138.230.100_667/:/www/wwwroot/chijing_storage/:/www/wwwroot/chijing_runtime/:/tmp/' > "$SITE_ROOT/.user.ini"
cat "$SITE_ROOT/.user.ini"
```

最后一行必须包含 `chijing_runtime`。如宝塔 PHP 已缓存配置，可在宝塔“软件商店 → PHP 8.0 → 服务”重启 PHP。

## 5. 安装并启动 AI 网关

网关是很轻量的 Python 进程：网页只拿到 2 分钟有效的登录票据；它负责保管 API Key、连接百炼并转发音频流。

```bash
apt-get update
apt-get install -y python3-venv

python3 -m venv "$RUNTIME/ai_gateway_venv"
"$RUNTIME/ai_gateway_venv/bin/python" -m pip install --upgrade pip
"$RUNTIME/ai_gateway_venv/bin/pip" install --no-cache-dir -r "$SITE_ROOT/ai_gateway/requirements.txt"

cp "$SITE_ROOT/ai_gateway/chijing-ai-gateway.service" /etc/systemd/system/chijing-ai-gateway.service
systemctl daemon-reload
systemctl enable --now chijing-ai-gateway.service
systemctl status chijing-ai-gateway.service --no-pager
```

看到 `active (running)` 即网关已启动。若没有启动成功，查看最近日志：

```bash
journalctl -u chijing-ai-gateway.service -n 80 --no-pager
```

常见原因是 `bailian.env` 中 API Key、模型名或文件权限填写不正确。

## 6. 配置 Nginx WebSocket 反向代理

编辑宝塔站点 Nginx 配置文件：

```bash
CONF=/www/server/panel/vhost/nginx/8.138.230.100_667.conf
cp "$CONF" "${CONF}.backup.$(date +%Y%m%d%H%M%S)"
nano "$CONF"
```

在该文件的 `server { ... }` 内、任意 PHP `location` 规则之前，加入：

```nginx
location ^~ /ai-gateway/ {
    proxy_pass http://127.0.0.1:8765/;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
    proxy_buffering off;
}
```

保存后检查并重载：

```bash
nginx -t && systemctl reload nginx
```

网关仅监听 `127.0.0.1:8765`，不会把 Python 端口直接暴露到公网。

## 7. 验证部署

先确认三个服务层：

```bash
systemctl is-active chijing-ai-gateway.service
ss -ltnp | grep ':8765'
curl -i http://127.0.0.1:8765/
```

前两条应分别显示 `active`、`127.0.0.1:8765`。最后一条显示 `401 Invalid or expired AI ticket` 是正常的：网关只接受登录网页签发的短时票据。

然后以正常账户登录网站，打开：

`http://8.138.230.100:667/assistant.html`

打开页面后，点击“开始”并允许浏览器麦克风权限，即可进行实时语音交互。

## 8. HTTPS 切换后必须做的两项修改

编辑运行时配置：

```bash
nano /www/wwwroot/chijing_runtime/ai/bailian.env
```

把这一行改为你的正式域名，例如：

```ini
AI_GATEWAY_ALLOWED_ORIGIN=https://example.com
```

然后执行：

```bash
systemctl restart chijing-ai-gateway.service
```

如果网站使用非标准 HTTPS 端口，Origin 必须带端口，例如 `https://example.com:8443`。

## 故障定位

| 现象 | 优先检查 |
| --- | --- |
| 页面提示“AI 助手暂不可用” | 是否已执行数据库迁移；`.user.ini` 是否包含 `/www/wwwroot/chijing_runtime/`；重启 PHP。 |
| 点击开始提示需要 HTTPS | 正常安全限制，绑定域名并启用 SSL 后再测试。 |
| WebSocket 连接失败 | `systemctl status chijing-ai-gateway`、Nginx 配置是否有 `/ai-gateway/`、`nginx -t` 是否通过。 |
| 网关日志显示鉴权/模型错误 | 检查 `BAILIAN_API_KEY`、业务空间地址及实际模型 API 名称。 |
| 有文字没有声音 | 浏览器是否静音；检查浏览器自动播放权限；模型会返回 24 kHz PCM，网页会自动播放。 |

## 安全边界

- 百炼 API Key 仅保存在服务器 `/www/wwwroot/chijing_runtime/ai/bailian.env`。
- 浏览器只得到一次性短期 HMAC 票据，不能用它读取 API Key。
- 每条会话和消息都通过当前 PHP 登录账户的 `user_id` 查询，用户之间不能互相读取。
- 助手内容不是医疗诊断。涉及疼痛、出血、肿胀、发热等情况，应提示用户线下就诊。
