# 口腔反光材料去除工具

## 项目介绍

本工具用于处理摄像头拍摄的口腔牙齿照片。拍摄时，摄像头周围的白色或青白色反光材料可能进入画面；程序会自动识别这些从图像边缘向内延伸的材料，在尽可能保留牙齿和口腔内容的前提下，将材料区域替换为纯黑色。

程序采用传统数字图像处理方法，不使用生成式 AI，不会生成、补绘或改变牙齿结构。未被掩膜覆盖的像素与原图保持一致。

## 主要功能

- 自动区分“大面积材料”和“细小光圈”，无需手动切换算法。
- 自动识别画面四周的白色、青白色反光材料。
- 通过边缘连通性区分周围材料与中央牙齿。
- 覆盖半透明白边和被阴影隔开的低亮度青白残片。
- 扩大输出范围，尽量保留更多牙齿内容。
- 将检测区域设置为精确的纯黑色 `RGB(0, 0, 0)`。
- 四阶段可视化：原图、白色候选、边缘确认、最终结果。
- 支持单张导出和图片集批量处理。
- 支持严格裁剪、黑色去除和透明 PNG 三种输出方式。

## 快速开始

### 方法一：直接启动

双击 `启动程序.bat`。

启动脚本会检查运行环境；如果缺少依赖，会自动调用 `安装依赖.bat` 安装。

### 方法二：手动安装和启动

在本目录打开命令行，依次执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

推荐使用 Python 3.10 或更高版本。

## 使用方法

1. 把待处理图片放入 `图片集` 文件夹，支持 JPG、JPEG、PNG 和 BMP。
2. 启动程序，在左侧列表中选择图片；也可以点击“打开其他图片”处理单张照片，或点击“选择图片文件夹”载入整个图片集。
3. 观察四个处理阶段：
   - **原始画面**：输入照片。
   - **白色候选**：根据亮度、饱和度和青白偏色得到的候选像素。
   - **边缘确认**：青色区域为最终检测掩膜，绿色框为保留输出范围。
   - **最终结果**：框内材料已经变为纯黑色。
4. 如果效果需要调整，可以修改左侧参数，再点击“重新处理”。
5. 点击“导出当前结果”保存单张图片，或点击“批量处理图片集”处理整个文件夹。

## 参数说明

| 参数 | 作用 | 调节建议 |
| --- | --- | --- |
| 最低亮度 | 白色候选的最低亮度 | 材料漏检时降低；牙齿误入候选时提高 |
| 最大饱和度 | 允许候选颜色偏离白色的程度 | 青色材料漏检时提高 |
| 青白偏色 | 控制蓝色分量与红色分量的差值 | 偏青材料漏检时降低限制 |
| 断点连接 | 连接材料中被纹理或阴影隔开的区域 | 材料掩膜破碎时提高 |
| 黑色覆盖扩张 | 向内扩展黑色区域，覆盖半透明白边 | 默认 28；程序会按大面积/细小光圈自动缩放，细小光圈有安全上限 |
| 内容保留率 | 从严格安全框向原图四周扩展 | 数值越高保留越多；100 表示保留完整原图 |

## 输出方式

### 保留牙齿（材料置黑，推荐）

尽量扩大画面范围，并将进入输出框的材料变为黑色。默认导出为无损 PNG，避免 JPEG 在黑色边缘产生灰白压缩晕边。

### 严格裁剪（无黑色区域）

只输出完全不含已识别材料的最大矩形区域。画面更紧凑，但可能裁掉部分牙齿或口腔内容。

### 透明去除（保留尺寸）

保持原图尺寸，将材料区域的 Alpha 通道设为透明。该模式必须保存为 PNG。

批量处理结果保存在 `处理结果` 文件夹。

## 算法流程

1. 统计图像四周的亮度分布，自动选择“大面积材料”或“细小光圈”模式。
2. 大面积模式结合 HSV 亮度、饱和度和 B-R 色差识别青白材料，填充材料内部断点，并吸收与材料相邻的宽暗青过渡区。
3. 细小光圈模式采用更严格的过曝白阈值，只保留与图像边界相连且面积足够的区域；不填充环形轮廓，避免把中间的口腔内容整体涂黑。
4. 对细小光圈进行平滑且有上限的黑色扩张，清理最后的白边，同时限制向牙齿方向的侵入。
5. 两种模式均通过边缘连通域分析排除中央牙齿高光。
6. 计算严格安全矩形，再根据“内容保留率”向原图扩展。
7. 将扩展框内的最终掩膜像素设置为纯黑色并无损导出。

## 隐私与注意事项

- 所有处理均在本机完成，程序不会上传图片或访问网络服务；仅首次安装 Python 依赖时可能需要联网下载软件包。
- 示例图片属于口腔影像，向他人分发文件夹前请确认具有相应授权。如不需要示例，可删除 `图片集` 中的图片，程序仍可通过“打开其他图片”使用。
- 本工具用于图像整理，不提供医疗诊断，也不会评估牙齿健康状况。
- 对不同相机、灯光或反光材料，可能需要调整检测参数。
