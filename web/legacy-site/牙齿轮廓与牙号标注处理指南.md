# 牙齿轮廓识别与 FDI 牙号标注处理指南

## 1. 文档目的

本文档用于指导其他视觉模型或自动化程序完成口内照片的牙齿轮廓识别、FDI 牙号判断、标注绘制、坐标导出和结果校验。

本流程来自一组 7 视角口内照片的实际处理经验。最重要的原则不是“尽量多画牙”，而是：

> 只标注照片中能够确认的真实牙体；一颗牙对应一个独立轮廓和一个唯一牙号。不能根据照片类型或“最深处”强行补牙。

---

## 2. 输入、参考图和输出图的角色

处理时必须明确每张输入图的用途，不能混用：

1. **干净原图**：最终输出的底图。所有非标注像素应尽量与原图完全一致。
2. **历史标注图**：只用于参考线条颜色、粗细、编号字体、位置和大致牙体边界。历史标注本身可能存在错误。
3. **用户修正图**：用户用蓝笔、箭头或文字指出的分牙范围，优先级最高。
4. **模型草稿图**：只能作为候选轮廓，不能未经校验直接交付。

优先级为：

`用户最新修正 > 干净原图中的真实牙体证据 > 已确认的历史结果 > 模型推测`

如果用户修改过某张结果图，后续必须以修改时间最新的版本为准，不能重新用旧版本覆盖。

---

## 3. FDI 两位牙号规则

### 3.1 象限

FDI 恒牙编号的第一位表示患者象限：

| 第一位 | 象限 |
|---|---|
| 1 | 患者右上 |
| 2 | 患者左上 |
| 3 | 患者左下 |
| 4 | 患者右下 |

注意：患者左右与观察者看到的图片左右可能相反。正面照中，通常图片左侧对应患者右侧，但仍要结合文件名、牙弓方向和中线确认。

### 3.2 牙位

第二位从中线向后排列：

| 第二位 | 牙齿 |
|---|---|
| 1 | 中切牙 |
| 2 | 侧切牙 |
| 3 | 尖牙 |
| 4 | 第一前磨牙 |
| 5 | 第二前磨牙 |
| 6 | 第一磨牙 |
| 7 | 第二磨牙 |
| 8 | 第三磨牙（智齿） |

例如：`11` 是患者右上中切牙，`27` 是患者左上第二磨牙，`41` 是患者右下中切牙。

## 4. “没有 8 号牙”的正确理解

“没有 8 号牙”只表示不应出现 `18、28、38、48`，不代表每张照片最深处都必须是 7 号。

照片可能只拍到：

- 尖牙或前磨牙；
- 第一磨牙，即 6 号；
- 第二磨牙，即 7 号；
- 被裁切的牙冠局部；
- 牙龈、颊黏膜或口腔暗区，而不是牙齿。

因此必须从可靠的前牙或形态学标志向后顺数，不能从“最深处假定为 7”反向编号。

错误做法：

1. 看到最深处有一个亮区，直接标成 7。
2. 为了凑到 7 号，把牙龈、暗影或同一牙齿的高光区域另画成一颗牙。
3. 一张图的最后轮廓有两个牙号，例如同一轮廓同时标 `41` 和 `31`。

正确做法：

1. 先确认中切牙、侧切牙、尖牙等解剖标志。
2. 按连续牙列向后编号。
3. 当牙体证据不足时停止编号，不补画不可见牙齿。

---

## 5. 牙齿识别顺序

建议采用“先定位、再分牙、最后编号”的三阶段流程。

### 5.1 定位牙弓和中线

首先判断：

- 上颌还是下颌；
- 患者左侧还是右侧；
- 中线在哪里；
- 牙列由前向后的延伸方向；
- 是否跨过中线拍到了对侧的一两颗牙。

不要仅凭文件名决定图像左右。文件名是重要提示，但必须与牙体形态互相验证。

### 5.2 利用形态学标志确定牙位

常用标志：

- 中切牙通常较宽、较平；
- 侧切牙通常比中切牙窄；
- 尖牙牙冠较长，切端或牙尖更明显；
- 前磨牙体积较小，常呈椭圆或双尖形态；
- 磨牙咬合面较宽，轮廓更大；
- 邻接牙之间应存在真实的邻接界线，而不是高光界线。

### 5.3 顺序编号

确定一颗可靠牙位后，沿牙列连续编号。编号序列必须满足解剖连续性，除非原图明确存在缺牙。

如果照片边缘只出现半颗牙，应判断它是否有可确认的独立牙冠。能确认时可以标注，但必须独立成一个轮廓；无法确认时不要因为暗影或亮斑而补画。

---

## 6. 轮廓绘制规范

### 6.1 轮廓对象

轮廓应围绕照片中可见的牙冠或牙体表面，不应包括：

- 牙龈；
- 嘴唇、舌体、颊黏膜；
- 口腔暗区；
- 镜面反光、高光斑；
- 阴影形成的假边缘；
- 相邻牙齿的部分区域。

### 6.2 一颗牙一个轮廓

每颗牙必须满足：

1. 一个独立闭合轮廓；
2. 一个唯一牙号；
3. 轮廓内部只对应这一颗牙；
4. 不允许嵌套轮廓；
5. 不允许两个牙号共享同一闭合区域；
6. 不允许存在没有牙号的牙齿轮廓。

相邻牙齿可以共享一段接触边界，但共享边界两侧必须形成两个不同的闭合区域。

### 6.3 裁切边缘处的牙齿

如果一颗牙被图片边缘裁切，仍决定标注时，应沿图片边缘补闭合线，使它成为一个可校验的闭合区域。不能留下开放轮廓后又给它编号。

### 6.4 线条样式

推荐：

- 轮廓颜色：高饱和荧光绿，例如 RGB `(0, 255, 0)`；
- 线宽：依据分辨率约 3–6 像素，保持整组图片一致；
- 线条抗锯齿；
- 不使用半透明大面积填充，以免遮挡牙体细节。

---

## 7. 牙号绘制规范

1. 使用 FDI 两位牙号。
2. 字体使用清晰的无衬线字体。
3. 颜色可使用红色或珊瑚红，与绿色轮廓形成明显区分。
4. 牙号必须放在轮廓外，不能覆盖牙冠表面。
5. 牙号与轮廓保持适当间距，不能压在线上。
6. 相邻牙号不能重叠。
7. 牙号放置方向应优先朝口腔空白区：
   - 正面或侧咬合图：上颌编号通常放在轮廓上方，下颌放在轮廓下方；
   - 张嘴或咬合面图：编号通常朝牙弓内侧的口腔空白区放置；
   - 图片边缘空间不足时，可以向侧面放置。

推荐计算方法：从牙齿中心沿指定方向发射射线，找到轮廓边界，再沿同方向移动“半个文字尺寸 + 间距”，将牙号中心放在该点。

## 8. 用户蓝笔修正的处理方法

蓝笔范围属于人工监督信号，应优先于模型原有轮廓。

如果用户说“蓝圈内实际是一颗牙”，处理步骤为：

1. 检测或人工读取蓝色笔迹范围；
2. 删除蓝圈内原有的多个错误绿色轮廓；
3. 根据蓝圈和原图牙体边界重画一个独立轮廓；
4. 删除多余牙号；
5. 后续牙号按连续牙列重新顺排；
6. 在干净原图上输出，最终结果不保留蓝笔。

本项目图 2 的经验：模型把两个大牙的亮暗区域分别拆成了两颗牙。用户用两个蓝圈指出，每个蓝圈实际只是一颗牙。修正后，上颌为 `11、21、22、23、24、25、26`，不能保留错误的 `12` 和 `27` 来维持原数量。

## 9. 推荐的模型工作流

不要让单个生成模型一次完成“识别、绘轮廓、编号、排版、保真”全部任务。推荐分为四步。

### 第一步：只做牙体实例识别

输出每颗可见牙齿的实例掩膜或多边形，不写牙号。要求模型回答：

- 发现多少颗真实牙齿；
- 每颗牙的中心点；
- 每颗牙的轮廓；
- 是否被裁切；
- 识别置信度。

### 第二步：独立完成牙号推理

依据视角、牙弓、中线、牙体形态和连续顺序，为已经确认的实例分配牙号。禁止为了补齐序列新增实例。

### 第三步：确定性绘制

由 OpenCV、Pillow 或其他确定性绘图程序在干净原图上绘制绿色轮廓和红色牙号。不要直接使用生成模型输出的照片作为最终底图。

### 第四步：结构化校验

校验通过后才写入最终文件夹。如果校验失败，返回具体牙号和错误类型，要求模型只修正失败区域。

## 10. 原图画质保护

生成模型经常会改变照片的纹理、曝光、牙齿形态或分辨率，即使提示中要求“保持不变”。因此建议只提取模型生成的标注层，不直接使用其整张输出。

推荐流程：

1. 读取干净原图；
2. 从模型草稿中按 HSV 提取高饱和绿色轮廓；
3. 屏蔽绿色、红色和蓝色标注区域；
4. 使用 ECC、特征匹配或已知缩放关系，将草稿配准到原图；
5. 只把绿色轮廓掩膜变换回原图；
6. 由程序重新绘制牙号；
7. 最终未标注区域直接复制原图像素。

可使用仿射配准矩阵：

```python
score, warp = cv2.findTransformECC(
    template_gray,
    resized_original_gray,
    np.eye(2, 3, dtype=np.float32),
    cv2.MOTION_AFFINE,
    criteria,
    valid_mask,
    5,
)
```

`valid_mask` 应排除模型图中的绿色轮廓、红色牙号和蓝笔区域，避免标注干扰配准。

## 11. “一个轮廓对应一个牙号”的自动校验

### 11.1 核心思想

将绿色线条视为边界，对非绿色区域执行连通域分析。每个牙齿中心点应位于一个闭合区域内。

校验条件：

1. 每个牙号中心位于闭合轮廓内部；
2. 该区域不能连接到图片边缘；
3. 不同牙号对应不同的连通域 ID；
4. 唯一连通域数量等于唯一牙号数量；
5. 牙号本身不能重复；
6. 闭合区域面积不能小到明显不合理；
7. 如有未分配的牙体大小闭合区域，应标记为“疑似无编号轮廓”。

### 11.2 OpenCV 示例

```python
import cv2
import numpy as np


def audit_one_contour_per_label(green_mask, labels):
    """
    green_mask: HxW，轮廓像素为 1
    labels: [(tooth_id, center_x, center_y), ...]
    """
    sealed = cv2.morphologyEx(
        green_mask.astype(np.uint8),
        cv2.MORPH_CLOSE,
        np.ones((5, 5), np.uint8),
    )

    open_space = (sealed == 0).astype(np.uint8)
    count, components, stats, _ = cv2.connectedComponentsWithStats(
        open_space, connectivity=8
    )

    border_ids = set(np.unique(np.concatenate([
        components[0, :],
        components[-1, :],
        components[:, 0],
        components[:, -1],
    ])).tolist())

    assignments = {}
    tooth_ids = [item[0] for item in labels]
    if len(tooth_ids) != len(set(tooth_ids)):
        raise ValueError("存在重复牙号")

    for tooth_id, x, y in labels:
        region_id = int(components[int(y), int(x)])

        if region_id == 0 or region_id in border_ids:
            raise ValueError(f"{tooth_id} 不在闭合轮廓内")

        if stats[region_id, cv2.CC_STAT_AREA] < 900:
            raise ValueError(f"{tooth_id} 的轮廓内部面积异常小")

        assignments[tooth_id] = region_id

    region_ids = list(assignments.values())
    if len(region_ids) != len(set(region_ids)):
        reverse = {}
        for tooth_id, region_id in assignments.items():
            reverse.setdefault(region_id, []).append(tooth_id)
        shared = [ids for ids in reverse.values() if len(ids) > 1]
        raise ValueError(f"一个轮廓对应多个牙号：{shared}")

    if len(set(region_ids)) != len(labels):
        raise ValueError("轮廓数与牙号数不一致")

    return {
        "contours": len(set(region_ids)),
        "labels": len(labels),
        "one_to_one": True,
    }
```

### 11.3 裁切牙的校验

裁切牙的轮廓会与图片边缘连通，默认会被判定为开放轮廓。若确定要标注该牙，应先沿图片边缘补闭合线，然后再运行校验。不能通过简单地关闭“边缘检测”来绕过校验。

## 12. 结构化坐标文件建议

每张图片建议保存同名 `.txt` 或 `.json`，不要只保留渲染后的 PNG。

推荐 JSON 格式：

```json
{
  "image": "2左侧咬合.jpg",
  "width": 1429,
  "height": 1026,
  "coordinate_system": "origin_top_left_xy_pixels",
  "teeth": [
    {
      "tooth_id": "11",
      "contour": [[24, 310], [31, 298], [45, 286]],
      "label_anchor": [93, 238],
      "cropped": false,
      "confidence": 0.96
    }
  ]
}
```

坐标约定必须写清：

- 原点在左上角；
- `x` 向右，`y` 向下；
- 坐标单位为原图像素；
- 多边形点按顺时针或逆时针排列；
- 第一个点无需在末尾重复，读取时自动闭合；
- 牙号使用字符串，避免 `11` 被误作普通序号；
- 坐标必须对应原图尺寸，而不是模型缩放图尺寸。

## 13. 常见失败模式及处理

### 13.1 把一颗牙拆成两颗

原因：高光、阴影、色差或修复体形成内部边界。

处理：检查所谓分界线是否真正延伸到牙冠边缘；如果用户蓝圈表明是一颗牙，删除内部假分界并合并轮廓。

### 13.2 一个轮廓标多个牙号

原因：编号阶段预设了牙齿数量，但轮廓阶段没有找到相同数量的实例。

处理：禁止“先列完整牙号再硬贴”。应以真实独立轮廓数量为基础重新编号；自动校验发现共享连通域时必须停止输出。

### 13.3 为了出现 7 号而画假牙

原因：误解“没有 8 号牙”，把画面最深处一律当作 7 号。

处理：从中线或已确认牙位向后顺数。若只到 6 号，就停止在 6 号。

### 13.4 把暗影或牙龈画成牙齿

原因：暗区中存在亮点或弧形边缘。

处理：确认是否存在连续牙釉质纹理、独立牙冠外形和与相邻牙的真实边界。单独亮点不是牙齿证据。

### 13.5 轮廓相互嵌套或重叠

原因：模型分别画了外轮廓和局部轮廓。

处理：每颗牙只保留一个实例掩膜；实例间允许共享边界，不允许内部面积重叠。

### 13.6 牙号放在牙体内部

原因：仅使用牙齿中心作为文字位置。

处理：从中心沿口腔空白方向找到边界，再把文字放到边界外。

### 13.7 模型输出导致画质下降

原因：生成模型重新合成了整张照片。

处理：只提取标注掩膜，配准回干净原图；最终输出不要使用模型合成的口腔照片作为底图。

## 15. 可直接交给其他模型的主提示词

```text
你正在处理口内牙齿照片。目标是识别照片中实际可见的每一颗牙，绘制独立闭合轮廓，并使用 FDI 两位牙号编号。

强制规则：
1. 只根据真实可见牙体判断牙齿数量，禁止根据照片类型预设数量。
2. “没有 8 号牙”只表示不能出现 18、28、38、48；画面最深处不一定是 7 号。
3. 必须从中线、切牙、尖牙等可靠标志沿牙列顺序编号，不能从最深处反推。
4. 一颗牙必须对应一个独立闭合轮廓和一个唯一牙号。
5. 不允许一个轮廓有多个牙号，不允许一个牙号对应多个轮廓。
6. 不允许嵌套、重叠、开放或无编号轮廓。
7. 用户蓝笔或人工修正范围优先级最高。如果用户说蓝圈内是一颗牙，必须删除内部假分界并合并为一颗。
8. 不要把高光、阴影、牙龈、舌、嘴唇、颊黏膜或口腔暗区当成牙齿。
9. 牙号必须放在轮廓外，不能遮挡牙齿细节。
10. 最终必须报告：独立闭合轮廓数、唯一牙号数、二者是否相等、是否存在共享轮廓。

执行顺序：
A. 先输出牙齿实例轮廓，不编号；
B. 根据已确认实例分配 FDI 牙号，禁止新增实例；
C. 执行一对一校验；
D. 只在校验通过后渲染最终结果。

输出要求：
- 绿色细线轮廓；
- 红色牙号位于轮廓外；
- 保持原图分辨率和非标注像素不变；
```
