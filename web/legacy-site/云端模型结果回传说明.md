# 云端模型结果回传

模型服务使用 `api/config.php` 中的 `MODEL_CALLBACK_SECRET` 认证。该密钥只能放在云端模型服务配置中，不能放入网页代码或 ESP32 固件。

## 1. 领取一条待分析任务

```http
POST /api/model_jobs.php?action=next
X-Model-Secret: <模型回传密钥>
```

无任务时：

```json
{"ok":true,"job":null}
```

有任务时：

```json
{
  "ok": true,
  "job": {
    "public_id": "202607211530001a2b3c4d5e",
    "member_public_id": "20260721151000f6e7d8c9b0",
    "member_name": "小明",
    "created_at": "2026-07-21 15:30:00"
  }
}
```

领取成功后，该记录由 `received` 改为 `processing`。

## 2. 读取私有图片

```http
GET /api/model_image.php?detection_id=202607211530001a2b3c4d5e
X-Model-Secret: <模型回传密钥>
```

响应为 JPEG 二进制。图片不会公开暴露，也不能通过普通网页 URL 直接访问。

## 3. 回传视觉模型或大模型结果

```http
POST /api/model_result.php
Content-Type: application/json
X-Model-Secret: <模型回传密钥>
```

```json
{
  "detection_id": "202607211530001a2b3c4d5e",
  "model_name": "oral-vision",
  "model_version": "1.0.0",
  "model_type": "vision",
  "status": "completed",
  "risk_level": "medium",
  "summary_text": "检测到疑似龋坏区域，建议结合口腔医生检查。",
  "raw_result_json": {
    "labels": [
      {"name": "caries", "confidence": 0.87}
    ]
  }
}
```

接口会在同一事务中：

1. 写入一条 `detection_results` 历史结果；
2. 更新 `detections.status` 为 `completed` 或 `failed`；
3. 更新 `detections.report_text`，供网页记录页直接展示；
4. 保存原始模型 JSON，供后续详情页、模型版本对比或重新分析使用。

模型失败时使用：

```json
{
  "detection_id": "202607211530001a2b3c4d5e",
  "model_name": "oral-vision",
  "model_type": "vision",
  "status": "failed",
  "risk_level": "unknown",
  "error_message": "模型服务暂时不可用"
}
```

模型服务应避免长时间占用任务；领取任务后若进程异常退出，需要由运维或后续重试程序将长期 `processing` 任务重新排队。
