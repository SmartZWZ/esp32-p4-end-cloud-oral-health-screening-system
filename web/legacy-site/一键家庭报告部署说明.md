# 齿镜“一键家庭报告”部署说明

## 功能处理顺序

1. 用户选择一位家庭成员。
2. 云端从该成员真实原始记录中选取最近最多 6 张有效照片。
3. 每张照片分别交给 AI 牙医生成一份独立观察报告。此阶段不读取本地模型结果，也不读取历史报告。
4. 同一批照片分别加入 `all_models` 本地模型队列。
5. AI 牙医只根据第 3 步的逐图独立报告生成成员级汇总。
6. 另一次独立 AI 调用只负责把本地模型的类别、数量、置信度和失败状态整理成“实验模型技术附录”，不得据此作医学判断。
7. 网页把两部分装订为一份报告并保存。打印页面可在浏览器中另存为带齿镜水印的 PDF。

## 一、上传文件

把本次压缩包解压到：

`/www/wwwroot/8.138.230.100_667`

至少确认下列新文件存在：

- `family-reports.html`
- `family-report-print.html`
- `api/family_reports.php`
- `assets/js/family-reports.js`
- `assets/js/family-report-print.js`
- `assets/css/family-reports.css`
- `assets/css/family-report-print.css`

下列既有文件也有修改，必须一并覆盖：

- `ai-dentist.html`
- `assets/js/app.js`
- `api/assistant_tools.php`
- `ai_gateway/tool_dispatcher.py`
- `database.sql`
- `database_ai_dentist_migration.sql`

## 二、执行 MySQL 迁移

在 phpMyAdmin 左侧先选中齿镜当前业务数据库，再执行：

`database_family_reports_migration.sql`

不要在 `information_schema` 页面执行。

执行成功后应出现：

- `family_reports`
- `family_report_images`

同时 `ai_dentist_call_logs.operation` 应包含：

- `family_image`
- `family_summary`
- `family_model_report`

如果“全部模型联合分析”还没有完成部署，还需要先执行：

`database_all_models_migration.sql`

## 三、检查 PHP 文件

服务器运行：

```bash
SITE_ROOT=/www/wwwroot/8.138.230.100_667

php -l "$SITE_ROOT/api/family_reports.php"
php -l "$SITE_ROOT/api/assistant_tools.php"
```

两条命令都应显示 `No syntax errors detected`。

## 四、重启 AI 网关

AI 助手新增了读取家庭报告的工具定义，覆盖代码后执行：

```bash
systemctl restart chijing-ai-gateway.service
systemctl status chijing-ai-gateway.service --no-pager
```

状态应为 `active (running)`。

本功能不新增百炼环境变量，不需要修改 `bailian.env`。

## 五、确认本地模型工作进程

家庭报告会一次创建最多 6 个 `all_models` 任务。Windows 本地模型电脑需要：

- 已登录 Tailscale；
- `D:\chijing_model_agent` 的常驻 worker 正在运行；
- worker 已是支持 `all_models` 的最新版本。

如果本地电脑离线，报告页面会停在“等待本地模型”。可以稍后恢复电脑继续，也可以在页面点击“跳过本地模型并继续”。

## 六、网页验证

1. 登录 `https://wwwxsh.cn/`。
2. 打开“AI牙医”。
3. 点击“一键家庭报告”。
4. 选择一位至少有 1 张有效照片的成员。
5. 点击“一键生成报告”。
6. 观察逐图 AI 报告和逐图模型任务进度。
7. 完成后检查：
   - 每张照片都有独立 AI 观察；
   - 页面有成员级 AI 汇总；
   - 本地模型位于独立的“实验模型技术附录”；
   - Tooth 输出默认折叠；
   - 历史报告可重命名、删除和再次打开。
8. 点击“下载 / PDF”，在浏览器打印窗口选择“另存为 PDF”，并打开“背景图形”，检查齿镜水印。

## 七、常见排查

### 页面返回“数据库迁移尚未执行”

确认在正确的齿镜业务数据库中执行了 `database_family_reports_migration.sql`。

### 一直等待本地模型

检查 Windows 本地 worker、Tailscale和云端模型队列接口。也可以先点击“跳过本地模型并继续”，确认 AI 报告链路本身正常。

### AI 单图观察失败

检查 AI 牙医后台配置、百炼额度和服务器 PHP 错误日志：

```bash
tail -n 150 /www/wwwlogs/8.138.230.100_667.error.log
```

### AI 助手看不到新报告

确认已覆盖 `assistant_tools.php` 和 `tool_dispatcher.py`，然后重启 `chijing-ai-gateway.service`。
