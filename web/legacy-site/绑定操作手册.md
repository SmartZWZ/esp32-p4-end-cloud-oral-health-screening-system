# 齿镜设备码绑定操作手册

本文适用于已经部署齿镜网站、并已烧录支持“设备码绑定”固件的 ESP32-P4 设备。

## 绑定前检查

- 已在齿镜网站完成注册并登录。
- ESP32-P4 已开机，并成功连接 Wi-Fi。
- ESP32-P4 显示屏显示“设备码”，例如 `CJ-7H4K-9M2Q-F8RX`。
- 设备与网站使用同一套服务器配置。

> 设备码不是二维码，也不会按时间自动刷新。请只输入设备屏幕当前显示的完整设备码。

## 首次绑定步骤

1. 登录齿镜网站，进入顶部导航中的“设备”。
2. 点击“绑定设备”。
3. 在设备屏幕查看设备码。
4. 在网页输入设备码，并填写便于识别的设备名称，例如“诊室一号齿镜”。
5. 点击“确认绑定”。
6. 网页出现“等待设备确认”后，不要关闭 ESP32-P4，也不要让它断开网络。
7. ESP32-P4 会自动完成以下操作：
   - 获取网页的绑定确认；
   - 生成新的设备码并保存；
   - 向云端同步新的设备码；
   - 获取并保存永久上传令牌；
   - 在屏幕显示绑定成功。
8. 网页提示“绑定完成”，设备会显示在“已绑定设备”列表中。

## 绑定后的使用

绑定完成后不需要在网页复制 Token，也不需要手工修改 ESP32-P4 的请求头。设备拍摄图片时会自动携带其保存的设备令牌上传，影像仅归属绑定该设备的账户。

## 设备码什么时候会改变

设备码只会在以下两种情况下变化：

1. 在 ESP32-P4 的设备设置中主动选择“更新设备码”。
2. 网页绑定成功后，ESP32-P4 自动执行一次设备码更新。

网络断开、服务器重启、网页等待超时都不会使设备码自动改变。

## 绑定未完成

网页确认后，硬件需在 15 分钟内完成联动。若超时：

- 网页本次确认自动取消；
- 设备码保持不变；
- 重新连接 ESP32-P4 网络后，使用同一设备码再次在网页发起绑定即可。

若提示“未找到该设备码”，请检查设备是否已经联网并完成设备登记；首次联网后等待几秒再尝试。

## 解绑与重新绑定

1. 在网页“设备”列表点击“解绑”。
2. 硬件的旧上传 Token 会失效，下一次上传会被服务器拒绝。
3. 让 ESP32-P4 进入设备码绑定模式；若需要，可在硬件端主动更新设备码。
4. 使用设备屏幕显示的设备码，在新账户或原账户重新绑定。

## 安全注意事项

- 不要在公开场合拍摄、截图或分享设备码。
- 不要将设备密钥、Wi-Fi 密码或设备上传 Token 告诉他人。
- 正式部署时必须使用 HTTPS；HTTP 地址只用于受控测试环境。
- 若怀疑设备码泄露，请在 ESP32-P4 端立即执行“更新设备码”，并检查网页设备列表。
